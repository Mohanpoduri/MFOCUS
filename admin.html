One-time Supabase configuration

How It Works

Photos are uploaded to Supabase Storage and the URLs are stored in a database. Your public portfolio (index.html) reads them — no login needed for visitors. Only your Google account can upload and delete.

🗄 Database · Supabase Postgres — free 500MB
🖼 Storage · Supabase Storage — free 1GB
🔐 Admin · Google OAuth (only your email)
👀 Visitors · Open — no login needed
🌐 Hosting · Vercel (already deployed)

Step 1 — Create Supabase Project

1
Go to supabase.com → Sign up free → New Project
2
Name it (e.g. mfocus), set a DB password, click Create and wait ~1 min
3
Go to Project Settings → API → copy your Project URL and anon public key
4
In both index.html and admin.html, replace YOUR_SUPABASE_URL and YOUR_SUPABASE_ANON_KEY. In admin.html also replace YOUR_GOOGLE_EMAIL@gmail.com

Step 2 — Create Database Table

Go to Supabase → SQL Editor → New Query and run:

create table photos (
  id uuid default gen_random_uuid() primary key,
  title text not null,
  category text not null,
  url text not null,
  storage_path text,
  created_at timestamptz default now()
);

alter table photos enable row level security;

create policy "Public read" on photos for select using (true);
create policy "Auth insert" on photos for insert with check (auth.role() = 'authenticated');
create policy "Auth delete" on photos for delete using (auth.role() = 'authenticated');

Step 3 — Create Storage Bucket

1
Supabase → Storage → New Bucket
2
Name exactly: photos → tick Public bucket → Create
3
Storage → Policies → for the photos bucket, allow authenticated users to INSERT and DELETE

Step 4 — Enable Google Login

1
console.cloud.google.com → New Project → enable Google+ API
2
APIs & Services → OAuth consent screen → External → fill name → Save
3
Credentials → Create → OAuth 2.0 Client ID → Web application
4
Authorized redirect URI: https://YOUR_REF.supabase.co/auth/v1/callback
5
Copy Client ID + Secret → Supabase → Auth → Providers → Google → paste → Enable
6
Supabase → Auth → URL Configuration → Redirect URLs → add: https://your-site.vercel.app/**

Step 5 — Redeploy

1
Push both updated files to GitHub → Vercel auto-deploys
2
Visit your-site.vercel.app/admin.html → sign in with Google → start uploading!
3
Share your-site.vercel.app anywhere — visitors see all photos, zero login needed ✓
